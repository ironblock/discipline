# Gate
- Skipped is not failed: No path filtering. An aggregator compares each job's result to the literal string `success`; `!failure()` passes on skipped. A filtered-out workflow leaves its required check pending forever.
- The registry is the pin: A gate discovered by globbing can silently find nothing. Required checks are enumerated explicitly at the root.
- Assert on structured failure classes, not message strings: Matching prose is grep-as-verdict one level up; it is why signatures go stale.
- A gate with a build step has a stale-binary axis: Stamp the binary that ran, not the tree's HEAD. Refuse a stale choice rather than pick one. *Specimen: a developer-machine gate graded with a release binary seven days behind the source, lacking a guard the source had carried all week. Four instruments defined a constant named after the environment variable they ignored.*
- Replace hardened instruments by parity, never by patch: The successor is seen red on every seeded fault beside the incumbent before the incumbent retires.
- Changing an instrument invalidates its numbers: Measure before and after; zero rows changed is the receipt.

- An injection is proven to change the tree before its verdict counts: The selftest fingerprints the sandbox either side of an injection and reports one that changed nothing as BROKEN, without running the gate at all, so it already asks the question. `scripts/check-injections.py` asks the same one in seconds rather than in a full run, and on every `verify.sh` invocation rather than only under `--selftest`: an inert injection arrives with an edit, and the edit is what should fail. *Specimen: a line-based merge spliced fourteen injection bodies into each other, every one inert; the gate itself stayed green throughout, because a gate does not run its own injections, and the selftest said "the injection changed nothing, so the case proves nothing" fourteen times, fifty-four minutes later.*
- An injection's input is invalid to every future version of both readers, not to the current subset: This is the failure the fingerprint CANNOT see. Growing a format retires the fault while the injection still writes a file, so the pre-flight passes and only the gate's verdict changes. *Specimen: `inject_regimen` wrote `arm = 1.5` to make a regimen.toml not a regimen; four days later the grammar grew floats, the document parsed, and the seeded case reported "the gate did not fire" -- on CI, seven minutes after a push whose local `verify.sh` was green.*
- Resolve the gate files by name, and let the pre-flight choose between two versions of one name: `verify.sh` and `faults.toml` are lists of named blocks, and a conflict hunk is an artifact of where two texts diverged -- git aligns two DIFFERENT injections on the identical boilerplate that opens their heredocs. `scripts/merge-gate.py` rebuilds each file from both sides by name, restores any body that is in neither parent, and where the two parents disagree runs the pre-flight to see which still bites. `red_faults` is COUNTED from the assembled list: base-plus-deltas double-counts whatever both branches inherited by two routes, which a stack of lanes built on each other produces routinely. *Specimen: six of eight lanes carried one body that was in neither parent; a seventh kept an injection whose anchor the other side had moved.*

## `faults.toml`
Extracted from the gate, gated in both directions (it can neither omit a proven fault nor claim an unproven one), every fault carrying a `failure_class`, relocated fixtures carrying `migrated_to` with their redness re-proven in the new home.

## Stage 2: the successor gate
The charter, ruled on the foundation PR and filed as #46. Keep the catch, remove the brittleness: the gate keeps proving every fault red, and the mechanism that keeps breaking -- prose signatures in a monolithic shell script -- is replaced.

- The diagnosis is structural, not incidental: The gates have been stable since the sixth CI run; every later failure was the selftest's own scaffolding. Mutation testing written in shell has no assertions, no fixtures and no structured failure output.
- Dispatch only, in stdlib Python: No build step, so the stale-binary axis disappears for the orchestrator itself. Zero new dependencies. A heterogeneous monorepo does not gate in one of its member languages. The orchestrator parses **only its own manifest format**; every program format is `diet check-*` through the resolver, with the binary path and its SHA-256 stamped in the run.
- Declare a check beside the code that emits it: A per-package `gate.toml`, so a package changes its own behaviour without editing the root -- and a root registry pinning which manifests must exist, because a gate discovered by globbing can silently find nothing.
- Assert on the class, never on the text: Every check emits `check`, `status`, `failure_class`. Changing a message must not break the selftest; changing a failure class must. This covers the harness and not only the checks: mechanics assertions are class-asserted and the scaffolding becomes a `unittest` suite whose own failures are typed. *Specimen: five stale message signatures, each caught, each requiring a fix in the root script for a change made in a package it does not own.*
- Migrate by parity per failure class, not per script: Every fault in `faults.toml` maps to a reproducing successor fault or a `migrated_to` naming the conformance fixture that replaces it. Relocated fixtures are re-proven red in their new home. `verify.sh` is deleted only in the change that shows the successor red on every fault.
- The hermetic sandbox is kept, not rebuilt: An allowlisted environment with stated reasons, `GIT_CONFIG_GLOBAL` and `GIT_CONFIG_SYSTEM` isolated, checks that read the environment tested under a faked one, and the injection pre-flight in the critical path. *Specimen: a sandbox inherited the runner's environment and read red while proving nothing.*
- The assembled stack is the truth: Per-branch fault counts are partial by construction -- nine lanes added faults independently and they reconciled only at assembly. `merge-gate.py` reconciles them; a count from one branch is not a number about the gate.
