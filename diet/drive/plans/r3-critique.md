## Checked and found sound

- **The captures.** In both streams, `timings` appears exactly once, on the `choices: []` chunk before `[DONE]`: at lines 1250/1254 of the `e7051ef` capture and 38/42 of the `4df29be` capture.

  - `grep` counts are 0 in both for `progress`, `tool_calls`, `"error"` and `prompt_n_cached`.
  - The first event after the headers is the role chunk. The data-line counts are 313 and 10.
  - `usage.prompt_tokens` equals `prompt_n + cache_n` in both.
- **`ab.json`.** 420 = 20 + 400, 125 = 40 + 85, and 420 = 335 + 85. `capture.py:54` reads `r["timings"]`.
- **The unmeasured dialect key.** The dialect reads `timings.prompt_n_cached` (`shape.rs:302`, read at `wire.rs:336-340`). The canned server replays it at `canned.rs:55,232,253,271`, and the client tests at `client/mod.rs:854,1361` and `wire.rs:641`. No capture in the repository contains it: a grep over the repository finds it only in code and in `gate.toml`.
- **The interactive session writes no journal or record.** `session.rs` has no journal or record references. The journal is projected only at `drive/mod.rs:1258`, and entries are pushed only by the unstreamed `Client`.
- **The transport's current behaviour.** `stream.rs:548-592` reads only `choices.first()`, and `[DONE]` yields `Finished { finish_reason }`. `Rejected` keeps the body verbatim.
- **The digits experiment, reproduced with exit codes read directly, not through a pipe.**
  - With `arbitrary_precision`: 20 of 20 numbers came back as written, and both captures exited 0.
  - Without it: the captures still exited 0, and a seeded `1.10` exited 1.
  - New: with the feature on, `2.9e2` re-renders as `2.9e+2`, which `Decimal::new` refuses. So an exponent is absent, as D1 intends.
- **The existing log fixtures.** `cargo test --test conformance` passes 36 tests (exit 0). All 14 valid v0 fixtures pass `diet check-log` (exit 0 each). The R3.2 acceptance filter `formats::log` matches 4 conformance tests, so it is not empty.

  - `a-float` uses `t: 10.5`, so it is unaffected while `t` stays a count.
