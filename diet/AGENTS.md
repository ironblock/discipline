# CONTENT
- Prose for judgment, schema for format, mechanical grounding for truth: Three layers; none substitutes for another. *Specimen: the model "can't do JSON" (false), "can do JSON" (8/8), and "does JSON too well" — 454 plausible API names emitted into a field whose definition invited enumeration; 248 existed nowhere.*
- Advisory framing for reference material; imperatives only at the cheapest effective site: Imperative injection causes over-pivoting and sycophantic capitulation on false positives; advisory framing preserves the model's ability to decline.
- One grammar per format, expressed as data, one authorized implementation: Anything else claiming to parse the format passes the shared conformance corpus or it isn't a parser of that format. *Specimen: eleven divergent decline-detection rules across three languages, and "I recreated it in Python to be quick."*


# MECHANISMS
- Fixtures pin what the author was thinking about: Conformance corpora and mutation find what nobody was.
- Salience needs a prior. A blind extractor has none: Extraction verifies provenance, never meaning.
- Any lane that writes with capture authority carries a mechanical groundedness gate against its contract input: Schema pressure generates to fill the form. Judgment-class fields (plans, opinions) are exempt — grounding them is a category error.
- Judgment compiled into data: Do the expensive judgment once, version it, and let cheap machinery apply it. A sense-description is a salience specification authored by a model capable of judgment, executed by a model capable only of distance. *Specimen: an abstract sentence matched concrete transcript prose at cosine 0.82.*
- Deterministic projections over interpretation chains: No subagent search parties where a purpose-built tool produces receipts at zero entropy. Every summarize-then-interpret hop is a lossy re-encode.
- One grammar per format under `diet/formats/<name>/`, with `fixtures/valid/` and `fixtures/invalid/` and a `.reason` beside each invalid fixture; the conformance test is the format's definition.
- The CLI (`diet check-*`, `diet parse-*`) is the only way anything outside this crate reads a format; the resolver refuses a stale or planted binary rather than choosing.
- The working object: patches are typed, dedup aliases rather than rebinds, a turn is atomic and order-independent (the permutation test), and the regimen is immutable for the session.


# GRADING
- Protocols amend by versioned bump, never in place: Vendor advice is input to the next version, not an override of the current one.
- Measured, not computed: Memory, cache, costs — measure. *Specimen: the ecosystem's own KV-cache arithmetic for a model family was wrong by 4×.*
- Any speculative or optimization path used in graded runs demonstrates output-invariance first: A throughput gain that changes outputs is a regime change wearing an optimization's clothes. *Specimen: a patched drafter selector raised decode speed and induced chain-of-thought loops; the acceptance math no longer described the proposer.*
- Truncated output is a typed outcome: A capped generation is never graded as wrong or malformed.


# ROLES
- Small models classify and disambiguate. They never trigger or generate on the authority path: Determinism first: lexical anchors, then embeddings, then a constrained verdict — and classical reconciliation merges the results.
- Judge seats are calibrated on hand-authored controls before trust, and judge prompts are pinned as instruments: *Specimen: one model scored at chance on controls it should have found easy; another scored 19/19 — the difference was capability, not ambiguity, and the calibration lived only in a session transcript until it was pinned.*
